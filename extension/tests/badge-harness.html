Pastille Prompt Tracker — interrupteur d'interception

La pastille est en bas à droite. chrome.storage.local est simulé : l'état écrit par l'interrupteur s'affiche ci-dessous, comme le ferait le popup.

  1. Cliquer l'interrupteur : la piste bascule, settings ci-dessous est mis à jour.
  2. Le clic sur l'interrupteur ne doit pas replier la pastille ; le clic sur le reste, si.
  3. Tab jusqu'à l'interrupteur (anneau de focus), puis Espace ou Entrée : même bascule.
  4. En mode verrouillé : grisé, non cliquable, tooltip « géré par ton organisation ».
